I

The project in brief

Purpose

An automated classifier that sorts incoming bug reports into Defects, Tasks and Enhancements, so that triage begins the moment a report is filed.

Outcomes

  • 94.34% accuracy with a stacking classifier
  • TF-IDF text features with SMOTE balancing
  • Ten algorithms evaluated side by side
  • An interactive report of the results

Approach

Ensemble learning over carefully processed text, paired with deliberate class balancing, rather than reliance on any single algorithm.

VI

Findings

  1. Ensembles outperform

    Stacking several algorithms reached 94.34%, more than two and a half points clear of the best single model.

  2. Language carries the signal

    TF-IDF features from bug summaries supplied the most predictive power; each class has a distinctive vocabulary.

  3. Balance is essential

    Without SMOTE, the dominant defect class swamps the minority classes. Balancing lifted performance markedly.

  4. Preparation compounds

    Careful feature engineering and preprocessing improved both accuracy and generalisation across every model.
